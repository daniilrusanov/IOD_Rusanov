# Експертне опитування — Самостійна робота №1 (ЛР1–ЛР4)

Веб-додаток для проведення розподіленого колективного ранжування об'єктів на основі преференційного голосування з інтегрованими лабораторними роботами 1-4.

## 🎯 Мета

Створення програмних засобів забезпечення розподіленого преференційного голосування для множини об'єктів з підтримкою:
- Налаштування предметної область та архівування даних
- Системи допомоги користувачеві
- Протоколювання всіх дій
- Розподіленого колективного ранжування методом перебору
- Конфіденційних та відкритих режимів роботи
- Управління обчисленнями та їх монітора  
- Графічної ілюстрації результатів
- Експорту результатів
- Редагування окремих ранжувань для аналізу

## 🚀 Функціонал

### ЛР1 — Голосування
- 20 об'єктів (мультфільми)
- 20+ експертів
- Пріоритетний вибір 3 об'єктів (множинне порівняння)
- Анонімне опитування з конфіденційністю
- Збереження даних для подальшої обробки

### ЛР2 — Вибір евристик
- Підмножина об'єктів з результатів ЛР1 (>10, <20)
- Вибір 2–3 евристик для звуження до макс. 10 об'єктів
- Відкрите опитування з протоколом
- Евристики та еволюційний алгоритм для ранжування

### ЛР3 — Колективне ранжування
- Матриця переваг та метрика Кука
- Повний перебір для n ≤ 10
- Еволюційний алгоритм для будь-якого n
- Синтетичні дані для масштабування
- Експорт результатів JSON

### ЛР4 — Розподілені компроміси
- **Ситуація А**: дані ЛР1–ЛР3
  - Централізований перебір
  - Розподілений перебір (Promise)
  - Розподілений перебір (Web Workers)
  - Порівняння результатів та часу
- **Ситуація Б**: велике n
  - Еволюційний алгоритм централізовано
  - Еволюційний алгоритм острівцями (distributed simulation)
  - Таблиця задоволеності експертів (індекс s%)
- Експорт протоколу у файл

### Допомога (Help)
- 10+ тем допомоги
- Пошук по темам
- Контекстна допомога
- Пов'язані теми

### Адміністративна панель
- Вкладка 1: **Протокол** - ЛР1-2 голоси, результати ранжування, популярність евристик
- Вкладка 2: **Налаштування** - конфігурація системи
- Вкладка 3: **Логи** - всі дії, експорт дат CSV/JSON
- Вкладка 4: **Редак. ранжувань** - редагування окремих голосів

## 📊 Новие модулі

### 1. Логування (`lib/logging.ts`) — Завдання 3

**Основні функції:**
- `logger.log(entry)` - залогувати дію
- `logger.getAllLogs()` - отримати все логи
- `logger.filterLogs(filters)` - фільтрування логів
- `logger.exportLogs(filename)` - експорт JSON
- `logger.exportLogsCSV(filename)` - експорт CSV
- `logger.clearLogs()` - очистити все логи

**Приклад:**
```typescript
logger.log({
  userType: 'admin',
  userName: 'admin',
  action: 'Вхід до панелі',
  module: 'Admin',
  details: { votesCount: 5 },
  status: 'success',
});
```

### 2. Конфігурація (`lib/configuration.ts`) — Завдання 1

**Основні функції:**
- `configManager.getConfig()` - отримати конфіг
- `configManager.updateConfig(updates)` - оновити конфіг
- `configManager.resetConfig()` - скинути на за замовчуванням
- `domainManager.getObjects()` / `addObject()` / `deleteObject()` - управління об'єктами

**Приклад:**
```typescript
const config = configManager.getConfig();
configManager.updateConfig({
  domainName: 'Нова область',
  bruteForceMaxN: 12,
});
```

### 3. Допомога (`lib/help.ts`) — Завдання 2

**Основні функції:**
- `helpSystem.getHelpTopic(id)` - отримати тему
- `helpSystem.getAllTopics()` - отримати все теми
- `helpSystem.searchTopics(query)` - пошук
- `helpSystem.getContextHelp(page)` - контекстна допомога
- `helpSystem.getRelatedTopics(id)` - пов'язані теми

**Приклад:**
```typescript
const topic = helpSystem.getHelpTopic('lab1_voting');
const related = helpSystem.getRelatedTopics('lab1_voting');
```

## 🌐 Конфігурація Supabase

Система підтримує локальне зберігання (localStorage) та синхронізацію з Supabase.

Файл: `.env` або `.env.local`
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

Без налаштування Supabase — дані зберігаються лише в localStorage.

5. **Порівняння** → аналізуються зміни медіан
